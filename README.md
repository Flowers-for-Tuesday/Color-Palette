# Color Palette

从 Pinterest 的 **𝐋𝐮𝐱 𝐃𝐞𝐬𝐢𝐠𝐧 𝐒𝐭𝐮𝐝𝐢𝐨 — Color Palette** 画板整理的配色资料。

**原始网址：** https://jp.pinterest.com/08lux_design/color-palette/

## 文件说明

- `original/`：377 张下载原图（`0001.png` 至 `0377.png`），仅在本地保存，已加入 `.gitignore`。
- `samples/`：从原图左上方裁出的示例图，与原图编号对应。
- `color-palettes.json`：377 条配色记录，包含日语标题、示例图、四色版、五色版和渐变版。

## JSON 字段

顶层采用按四位序号索引的对象结构，键为 `0001` 至 `0377`。每条方案及其配色字段使用两空格缩进、分行展开，日语标题以 UTF-8 原文保存。

读取单条方案可使用 `data["0001"]`；遍历全部方案可使用 JavaScript 的 `Object.values(data)` 或 Python 的 `data.values()`。原先按数组下标读取的代码需要相应调整。

| 字段 | 说明 |
| --- | --- |
| `id` | 序号，对应原图路径，如 `1` 对应 `original/0001.png` |
| `title` | 日语配色标题 |
| `image` | 裁切示例图的相对路径，如 `samples/0001.png` |
| `colors4` | 原图底部从左到右排列的四种颜色，每项包含英文名 `name` 和 HEX 色值 `hex` |
| `colors5` | 原图右侧从上到下排列的五种颜色，以 HEX 字符串数组保存 |
| `gradients` | 原图从上到下排列的三组渐变，每项用 `from`、`to` 表示左端和右端的 HEX 色值 |

原来的 `colors` 字段已更名为 `colors4`。各版本分别保留对应区域的 HEX 文字标注；部分原图的标注与色块实际颜色或 RGB 数字存在差异。

编号 `199`、`200`、`211`、`214` 为应用示例，没有完整的配色标注区域，分别沿用编号 `263`、`360`、`368`、`336` 的四色、五色和渐变数据；其裁图仍来自应用示例自身。
